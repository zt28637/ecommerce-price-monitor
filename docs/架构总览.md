# 架构总览

> 本文只描述**当前跑得起来的架构**：边界、进程模型、节点、契约与关键决策。
> 内部施工状态与实测记录不在此展开。

---

## 0. 一句话

> 影刀负责**触发和调度**，Python 旁路进程负责**采集 → 清洗 → 入库 → 告警**；采集层通过 CDP 接管一个固定的 Edge 登录态，单实例、单 tab、顺序执行。

---

## 1. 系统边界

| 在范围内 | 不在范围内 |
|---|---|
| 淘宝搜索结果列表采集（N1） | 多账号 / 多采集机 / 代理池 |
| 商品详情与 SKU 采集（N2） | 自动过滑块、验证码识别、逆向签名 |
| 清洗、分级、日报（N3） | 运营发起按钮、权限体系、审批流 |
| MySQL 星型入库（N4） | 自动改价、自动上下架 |
| 价格告警与飞书通知（N5） | 调度平台、BI 看板 |
| Excel 配置 → 跑批 → 状态回写（业务侧） | 完整编排层（已归档） |

**定位**：面试作品 / 单机跑批工具，不是多租户产品。

## 2. 分层与进程模型

```text
┌─────────────────────────────────────────────────────┐
│ 影刀应用：主流程 main + 配置预览                     │
│   配置预览 → 运行 run_batch.bat                      │
│   → 读 runtime/state/last_batch.txt                  │
│   → 成功打开日报 / 失败与异常走 notify_*.bat → 飞书  │
└───────────────────────┬─────────────────────────────┘
                        │ 一次 bat 调用（wait_to_complete）
                        ▼
┌─────────────────────────────────────────────────────┐
│ run_batch.bat → run_batch_launcher.py → Python       │
│ run_batch.py：N0 → N1 → N2 → N3 → N4 → N5            │
│ 单实例锁 / 阶段日志 / last_batch.json + txt          │
└───────────────────────┬─────────────────────────────┘
                        │ Playwright connect_over_cdp
                        ▼
┌─────────────────────────────────────────────────────┐
│ 系统 Edge（固定 profile，127.0.0.1:9223）            │
│ 登录态常驻；N1/N2 只 attach，不新建 context          │
└─────────────────────────────────────────────────────┘
```

### 关键边界

| 边界 | 做法 | 说明 |
|---|---|---|
| 影刀 ↔ Python | **一次 bat 调用** | `run_batch.bat` 是唯一入口；N0–N5 在同一进程里顺序执行 |
| Python ↔ 浏览器 | CDP `connect_over_cdp` | 接管真实 Edge；不下载 Chromium，不注入 stealth 补丁 |
| 登录态 | 固定 `runtime/profile` | 不在每轮重新登录；允许人工完成登录 |
| 并发 | 单实例锁 | 锁在 `run_batch`，N1/N2 不抢锁 |
| 代码位置 | 全部在仓库 `model/` | 不搬进影刀；旁路进程便于测试与隔离 |
| 服务化 | 不做 HTTP 服务 | 当前是“一 bat 边界”，没有逐节点进程需要包装 |

## 4. 数据流与契约

```text
config/监控关键词.xlsx
        │ config_excel.sync（校验后写，失败不覆盖旧配置）
        ▼
config/targets.json
        │ N1
        ▼
runtime/list_raw/<keyword>/<run_ts>.jsonl
        │ N2（同时传 list_jsonl + search_url + keyword + pages）
        ▼
runtime/detail_raw/<ts>.jsonl
        │ N3
        ▼
runtime/clean/<YYYYMMDD>/{item,sku,inventory,anomalies}.jsonl
        + 日报_<date>.xlsx / run_meta.json
        │ N4（只收 auto_pass / approved；一个批次一个事务）
        ▼
MySQL：dim_product / dim_sku / fact_item_price / fact_sku_price / ingest_batch
        │ N5
        ▼
runtime/alerts/<YYYYMMDD>/{alerts.jsonl, 告警_<date>.md, summary.json, push_log.jsonl}
        │ notify（file 默认 / feishu 可选）
        ▼
飞书群 / 本地文件
```

### N1 → N2

N1 行字段（N2 只取以下）：

```text
product_id, title, price, price_raw, sales, shop_name, prov_city,
main_image_url, detail_url, platform, is_promoted, card_href
```

推广位（`is_promoted=1`）在 N1 过滤阶段直接丢弃，不占 `target_n`。

### N2 → N3（冻结契约，只加不改）

```text
crawl_date, crawl_ts, product_id, title, shop,
item_price, item_price_raw, price_desc, item_price_scope, hide_other_price,
price_coverage, price_complete, flags,
sku_id, prop_path, prop_names, price, price_raw,
quantity, quantity_text, in_stock,
retry_count, url
```

可选加：`source_mode`（ice / mtop_price / mtop_full）、`entry_mode`（click / href_fallback）、`search_page`。

**口径**：

- 列表价 `price_role=list_trigger`，只做触发器；
- 详情价 `price_role=detail_trend`，趋势与告警以详情价为准；
- 掩码价 / 部分价 / 0 价只打 `flags`，不在 N2 判可用性；
- N3 按 `(product_id, sku_id, crawl_date)` 优先最新 `price_complete=true` 一行。

### N3 → N4 → N5

| 交接 | 契约 |
|---|---|
| N3 → N4 | `clean/<date>/` 下 item/sku/inventory JSONL；N4 只收 `auto_pass` / `approved`；优先 `*_reviewed.jsonl` |
| N4 → N5 | 只读 MySQL；N5 要求详情价 `price_complete=1`；列表价只进日报 |
| N5 → 通知 | `notify.alert()`；默认 file 通道，`--send` 才联网；日志不打印 webhook URL |

## 5. 运行产物与配置

```text
config/
├── targets.json              # N1 唯一采集配置源（由 Excel 生成）
├── 监控关键词.xlsx            # 运营编辑的配置表
├── database.json             # MySQL（gitignore）
├── alert.json                # 告警阈值/通道
└── alert_local.json          # 飞书 webhook/secret（gitignore）

runtime/                      # 全部运行产物（gitignore）
├── list_raw/ · list_html/
├── detail_raw/ · detail_json/ · detail_html/ · detail_mtop/
├── clean/ · alerts/
├── run_log/ · state/ · profile/
└── _test/                    # 离线用例与烟测
```

| 文件 | 读者 | 内容 | 是否提交 |
|---|---|---|---|
| `config/targets.json` | N1/N2/N3 | 关键词、价格带、include/exclude、max_pages、target_n；**单目标** | 是 |
| `config/database.json` | N4/N5 | host/port/user/password/database | 否 |
| `config/alert.json` | N5 | 阈值、通道、冷却 | 是 |
| `config/alert_local.json` | N5 | 飞书 webhook/secret | 否 |
| `runtime/state/collect.lock` | run_batch | `{pid, ts, tag}`；TTL + 进程存活判断 | 否 |
| `runtime/state/last_batch.json` | 机器 | `run_id/date/status/reason/run_log/outputs` | 否 |
| `runtime/state/last_batch.txt` | 人 / 影刀 | 一行：`status \| reason \| run_log` | 否 |

**状态值**：`running` / `completed` / `partial` / `blocked` / `failed` / `already_running`。

**续跑**：

- N1 不做轮内续跑，重跑整轮；
- N2 按当天 `detail_raw` 的 `product_id` 续跑；
- N3/N4 幂等：同输入产物哈希一致；N4 同日 upsert 行数不增。

## 6. 异常、风控与节流

| 层 | 机制 | 代码 |
|---|---|---|
| N1 | URL 风控域 + 可见滑块/验证码 DOM；登录域；0 卡诊断 | `classify.py` |
| N1 | 翻页失败先诊断，登录/风控/结构 → 停整轮；否则停扫描并保留已采页 | `collect_list._pager_fail` |
| N2 | 搜索页就绪、点卡前、点卡后、等数据后快照；硬风控 → `risk` + `stop` + `risk.json`；同 tab 留证；`continue_slow` 降速 | `policy.py` / `risk_state.py` / `card_click.prepare_search` |
| N2 | 返回搜索页校验页码；中断不误记 `no_card`，剩余留 `remaining` | `card_click.return_to_search` |
| N2 | 连续技术失败达阈值 → `circuit_open` | `collect_detail` |
| 业务侧 | 阶段 stop → `blocked`；异常 → `failed`；通知 | `run_batch.py` |
| 全局 | 单实例锁；不并发、不多账号、不代理 | `single_instance.py` |

**节奏参数**：商品间基础间隔 + 小比例长尾 + 随机长停；`load_slow` / `mtop_abnormal` / `warn_text` / `session_age` 触发倍率；单次封顶，可整体关闭。参数按真机 canary 校准后再固化。

## 7. 关键决策

| 决策 | 理由 |
|---|---|
| 采集层统一 Playwright，CDP 接管真实 Edge | 避开 `navigator.webdriver`；不下载 Chromium |
| 登录层单一入口重建，旧实现不迁移 | 避免双入口漂移 |
| N2 点卡主路径；href 只做兜底，默认关 | 点卡价格覆盖更稳；href 有时效 |
| ICE 主解析；mtop 页内兜底，默认 `auto` | 主路径零额外请求；ICE 不完整才补 |
| 代码不搬进影刀，保留 Python 旁路 | 可测试 / 隔离 / 仓库即 SSOT |
| 不做 HTTP 服务 | 当前是一 bat 边界，没有逐节点进程要包装 |
| 锁归调用方 `run_batch` | 编排层暂缓，锁放在唯一入口 |
| **默认单目标**；Excel 多行启用 → 配置错误 | N1 只读 `targets[0]`，静默丢配置不可接受 |
| 详情 `remaining` / 中断 reason → 批次 `partial` | 不能把“没扫完”报成 `completed` |
| href 兜底只在正常扫完时生效 | 中断后直开 `card_href` = 批量裸跳详情 |
| 风控状态机：`risk.json` 冷却 + 点卡前检查 + 时间线 + 同 tab 留证 | 命中后有状态、有证据、可调节奏 |
| 指纹自检只读、不注入补丁 | 确认 CDP 接管的是真实 Edge |
