## 2. 子节点（施工粒度）

### N0 登录

| 子节点 | 内容 |
|---|---|
| N0.1 | 启动 / 复用固定端口 + profile |
| N0.2 | 判活（cookie / URL / 页面结构） |
| N0.3 | 恢复阶梯（快速进入 / 人工 / 冷却） |
| N0.4 | 事件日志（`login_at` / `session_age_hours`） |

### N1 列表

| 子节点 | 内容 |
|---|---|
| N1.1 | 准备搜索页（关键词 / 销量排序 / 价格区间） |
| N1.2 | 拟人滚动到底（懒加载全覆盖） |
| N1.3 | 解析卡片（ID / 标题 / 价格 / 销量） |
| N1.4 | 过滤 / 去重 / 截断（include/exclude/价格/target_n） |
| N1.5 | 翻页（失败即停，保留已采页） |
| N1.6 | 落盘 / 日志（JSONL append + fsync） |

### N2 详情

| 子节点 | 内容 |
|---|---|
| N2.1 | 启动与准备（三选一输入 / 参数校验 / 已完成过滤） |
| N2.2 | 搜索上下文 + 找卡 / 点击 / 扫描 / 翻页 / 返回校验 |
| N2.3 | 等数据 / ICE 解析 / pid 校验（mtop 兜底） |
| N2.4 | 风控与失败分类（冷却 / 时间线 / 同 tab 留证） |
| N2.5 | 落盘与续跑（JSONL / ICE / HTML / run_log） |
| N2.6 | 重启与健康检查（暂缓） |

### N3 / N4 / N5

```text
N3：输入读取 → 列表清洗 → 详情清洗 → 合并 → 分级剔除 → 落盘报表 → 幂等对账
N4：入口编排 → 连接 → 建表视图 → 维度（SCD2）→ 事实（upsert）
N5：规则与构建 → 渲染与通知 → 编排与去重
```
