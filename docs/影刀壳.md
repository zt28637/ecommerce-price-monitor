# 影刀壳 · 业务编排

> 影刀只做**业务入口**：Excel 预览、触发跑批、状态判断、失败/部分完成通知。
> 采集、清洗、入库、告警全部在 Python 进程内完成，不在画布写业务分支。

---

## 1. 主流程 `main`

```text
001  打印日志  info     开始跑批：竞品价格监控
002  Try
003  调用流程             process1 → 配置预览
004  运行或打开           run_batch.bat --send --send-daily
                         （wait_to_complete，超时 4h，最小化）
005  读取文件             runtime/state/last_batch.txt → 状态文本
006  IF 条件              状态文本 包含 "partial"
007    打印日志  warning   "跑批部分完成：" + 状态文本
008    打开文件夹         runtime/clean
009    运行或打开         notify_partial.bat（通知“部分完成”）
010  Else
011    IF 条件            状态文本 包含 "completed"
012      打印日志  info    "跑批完成：" + 状态文本
013      打开文件夹       runtime/clean
014    Else
015      打印日志  warning "跑批失败：" + 状态文本
016      运行或打开       notify_failure.bat
017    End IF
018  End IF
019  Catch
020    写入文件           runtime/state/shadowbot_error.txt = "影刀调用异常：" + str(exception)
021    打印日志  error    "影刀调用异常：" + str(exception)
022    运行或打开         notify_error.bat
023  End Try
```

**状态口径**：

- `run_batch` 把“详情扫描中断 / 有 `remaining`”记为 `partial`；
- 画布把 `partial` 走警告分支（打开日报 + 部分完成通知），不再静默当成功；
- `completed` 才走成功分支；其它走失败通知。

## 2. 配置预览 `配置预览`

```text
001  打开/新建 Excel     启动方式=open  驱动方式=openpyxl
                         Excel 路径=config/监控关键词.xlsx  isvisible=False
002  读取 Excel 内容     读取方式=used_range  Sheet=监控关键词
                         has_header_row=False → 变量 配置行
003  ForEach 列表循环     列表=配置行 → 当前行
004    IF 条件            当前行[0] in ["是","true","1","✓","√"]
005      打印日志  info    "启用目标：" + 当前行[1] + " / " + 当前行[2]
006    End IF
007  循环结束标记
```

> 用 `openpyxl` 驱动，不弹 Excel 窗口；不调 `excel.close`（openpyxl 没有 UI 可关）。

## 3. 状态与通知

| 文件 | 读者 | 内容 |
|---|---|---|
| `runtime/state/last_batch.json` | 机器 | `run_id/date/status/reason/run_log/outputs` |
| `runtime/state/last_batch.txt` | 人 / 影刀 | 一行：`status \| reason \| run_log` |
| `runtime/state/shadowbot_error.txt` | 维护者 | `Catch` 捕获的影刀异常 |

通知链（复用 N5，不在画布重配飞书）：

```text
notify_failure.bat / notify_partial.bat / notify_error.bat
  → notify_launcher.py（ASCII 路径启动器）
  → model/7.业务侧/notify_cli.py
  → model/5.价格告警/notify.py  alert()
  → config/alert_local.json（默认 feishu）
```

- `notify_cli.py --dry-run` 可校验通道，不发消息；
- `notify_partial.bat`：`--status-file runtime/state/last_batch.txt --title "竞品监控部分完成"`；
- 004 参数 `--send --send-daily`：跑批成功后自动推飞书日报；失败/异常分别走独立通知。

---

## 4. 运行方式

| 场景 | 操作 |
|---|---|
| 全量 | 直接运行 `main`（默认今天、`config/监控关键词.xlsx`） |
| 烟测（不启浏览器/库） | 004 参数临时填 `--only clean --no-lock`，跑完清空 |
| 指定日期 | 004 参数填 `--date YYYY-MM-DD` |
| 入库演练 | 004 参数填 `--dry-run --database <测试库>` |

**已知限制**：`配置预览` 固定读 `config/监控关键词.xlsx`；若 004 用 `--excel` 指向别的文件，预览和跑批会不一致。日常只用默认路径，不受影响。
