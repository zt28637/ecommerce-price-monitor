> **展示仓说明**：本仓库不包含 N0–N2（登录 / 列表 / 详情）实现；文中出现的 `model/0.*`、`model/1.*`、`model/2.*` 路径指向私有仓库，仅用于说明契约与边界。

# 节点契约

> 每个节点都是“输入 → 动作 → 输出 + 失败分类”。调用方只依赖这里的字段；节点内部实现可替换。

---

## N0 登录

| 项 | 内容 |
|---|---|
| 入口 | `login_entry.ensure_login()` |
| 输入 | 固定 profile、`manual_wait` |
| 输出 | `state=logged_in / cold_down`；`result`、`detail`、`run_log` |
| 日志 | `runtime/run_log/login/*.jsonl`（事件流、`login_at`、`session_age_hours`） |
| 失败分类 | `browser_down` / `attach_failed` / `risk` / `probe_failed` / `cred_missing` / `budget_blocked` / `manual_required` / `captcha` / `slider` / `password_failed` / `timeout` / `unverified` / `structure_error` |

原则：能采返回 `logged_in`；不能采按恢复阶梯处理，给下游明确状态，不让采集层在未登录浏览器上继续跑。

## N1 列表

| 项 | 内容 |
|---|---|
| 入口 | `collect_list.run()` |
| 输入 | `targets.json` 第一个目标（keyword / 价格带 / include / exclude）、`max_pages`、`target_n` |
| 输出 | `runtime/list_raw/<keyword>/<run_ts>.jsonl` + `runtime/run_log/<run_ts>_list.json` |
| 成功 | `passed_p > 0` 且 `reason == ""` |
| 关键计数 | `raw_n`（解析卡片）/ `filtered_m`（丢弃）/ `passed_p`（落盘），要求 `N = M + P` |

落盘行字段：

```text
product_id, title, price, price_raw, sales, shop_name, prov_city,
main_image_url, detail_url, platform, is_promoted, card_href
```

失败分类：

| reason | 含义 | 停整轮 |
|---|---|---|
| `input_config_missing` | 配置缺失/非法 | 是 |
| `browser_down` / `not_login` | 浏览器或登录态不可用 | 是 |
| `risk_page` | 风控域 / 可见滑块·验证码 | 是 |
| `prepare_failed` / `filter_failed` | 搜索页或价格区间操作失败 | 是 |
| `no_result` | 有明确“无结果”证据 | 否 |
| `structure_changed` | 0 卡片无证据 / DOM 与解析不一致 | 是 |
| `pager_failed` | 翻页失败，保留已采页 | 否（数据可用） |
| `exception: ...` | 未预期异常，保留已落盘页 | 否（数据可用） |

## N2 详情

| 项 | 内容 |
|---|---|
| 入口 | `collect_detail.run()` |
| 输入 | `list_jsonl` / `urls` / `product_ids` 三选一；click 模式另需 `search_url` + `keyword` + `scan_pages` |
| 关键参数 | `entry_mode`（click / href）、`risk_cooldown_min`、`pace_enabled`、`mtop_policy`（off / auto / force） |
| 输出 | `detail_raw/<ts>.jsonl`、`detail_json/<pid>/<day>.json`、异常 HTML、`detail_mtop/`、`run_log`、`state/risk.json` |
| 成功 | `failed == 0 and done > 0 and reason == ""` |
| 关键计数 | `total` / `requested` / `done` / `failed` / `business_skipped` / `remaining` / `risk_hits` / `source_counts` |

落盘行字段必须覆盖 N3 冻结契约：

```text
crawl_date, crawl_ts, product_id, title, shop,
item_price, item_price_raw, price_desc, item_price_scope, hide_other_price,
price_coverage, price_complete, flags,
sku_id, prop_path, prop_names, price, price_raw,
quantity, quantity_text, in_stock,
retry_count, url
```

只允许加字段（`source_mode` / `entry_mode` / `search_page`），不改名、不删字段。

失败分类（代表）：

| 类别 | reason |
|---|---|
| 输入/上下文 | `input_config_missing` / `no_input` / `search_context_missing` |
| 浏览器/登录 | `browser_down` / `browser_restart_failed` / `not_login` |
| 风控 | `risk` / `risk_cooldown` / `mtop_risk` |
| 熔断/结构 | `structure_changed` / `circuit_open` |
| 翻页/返回 | `pager_failed` / `page_mismatch` / `return_mismatch`（只停扫描，剩余留 `remaining`） |
| 单商品技术失败 | `click_failed` / `open_error` / `timeout` / `ice_missing` / `res_missing` / `item_missing` / `pid_mismatch` |
| mtop 兜底 | `mtop_unavailable` / `mtop_failed` / `mtop_incomplete` / `mtop_budget`（回退 ICE 或停兜底） |
| 业务跳过 | `no_card` / `title_search_error`（`business_skipped`，不算失败） |

边界：

- `business_skipped` 从 `requested` 中扣除，不计失败；
- 单商品失败只进 `errors[]`，不改变整轮 `reason`，除非触发熔断/结构停；
- `pager_failed` 数据仍可用，不停整轮；
- `remaining` 包含“没扫到、不证明不存在”的商品，调用方据此报 `partial`。

## N3 清洗

| 项 | 内容 |
|---|---|
| 入口 | `run_clean.run()` |
| 输入 | `list_raw` + `detail_raw`（同日全部轮次）+ `date` + 阈值 |
| 输出 | `runtime/clean/<YYYYMMDD>/`：item / sku / inventory / anomalies JSONL、Excel 日报、`run_meta.json` |
| 规则 | 红黄绿分级；红标不进表；黄标保留并打 `flags`；列表价只做触发器 |
| 幂等 | 同输入产物哈希一致；按 `(product_id, sku_id, crawl_date)` 取最新完整行 |

## N4 入库

| 项 | 内容 |
|---|---|
| 入口 | `run_ingest.run()` |
| 输入 | `clean_dir`、`database.json`、`dry_run` |
| 输出 | MySQL：`dim_product` / `dim_sku` / `fact_item_price` / `fact_sku_price` / `ingest_batch` + 4 视图 |
| 规则 | 只收 `auto_pass` / `approved`；一个批次一个事务；同日 upsert 行数不增；支持回滚 |
| 维度 | SCD2；迟到数据打标记 |

## N5 告警

| 项 | 内容 |
|---|---|
| 入口 | `run_alert.run()` |
| 输入 | MySQL、`alert.json`、`date`、`send` |
| 输出 | `runtime/alerts/<YYYYMMDD>/`：alerts.jsonl、告警_*.md、summary.json、push_log.jsonl |
| 规则 | 涨跌绝对值/百分比阈值；稳定 `alert_id`；24h 冷却；日报冷却；只对 `price_complete=1` 的详情价判断 |
| 通知 | 默认 file 通道；`--send` 才联网；支持飞书（webhook + 签名）；日志不打印 URL |

## 业务侧

| 项 | 内容 |
|---|---|
| 入口 | `run_batch.run()` |
| 输入 | `config/监控关键词.xlsx`、CLI 参数 |
| 输出 | 阶段 `run_log`、`runtime/state/last_batch.json/txt`、通知 |
| 状态 | `running` / `completed` / `partial` / `blocked` / `failed` / `already_running` |
| 规则 | 单实例锁；阶段 stop → `blocked`；异常 → `failed`；详情 `remaining` → `partial` |
