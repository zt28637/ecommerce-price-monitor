## 附录A：10张图最终SQL（全部只查 `v_*` 视图，不查原始表）

**A1 监控商品数**（指标卡/Scalar，6×3）
```sql
SELECT COUNT(DISTINCT product_id) AS 商品数 FROM v_sku_latest
```
**A2 监控 SKU 数**（指标卡，6×3）
```sql
SELECT COUNT(*) AS SKU数 FROM v_sku_latest
```
**A3 覆盖店铺数**（指标卡，6×3）
```sql
SELECT COUNT(DISTINCT shop_name) AS 店铺数 FROM v_sku_latest
```
**A4 已采集天数**（指标卡，6×3）
```sql
SELECT COUNT(DISTINCT crawl_date) AS 天数 FROM v_price_daily
```
> 指标卡要求结果 **1行1列**；多KPI同排=建多个卡或用表格图。

**A5 每日采集量与均价趋势**（折线/Line，14×8）
```sql
SELECT crawl_date AS 采集日期,
       ROUND(AVG(price), 2) AS 均价,
       COUNT(*) AS 当日SKU数
FROM v_price_daily
GROUP BY crawl_date
ORDER BY crawl_date
```
**A6 店铺均价 TOP 15**（横向条形/Horizontal bar，10×8）
```sql
SELECT shop_name AS 店铺, avg_price AS 均价, sku_count AS SKU数
FROM v_shop_summary
WHERE avg_price IS NOT NULL
ORDER BY avg_price DESC
LIMIT 15
```
> 必须横向条形+TOP N 截断：竖向39店铺×3系列柱图每根<5px读不出；中文长店名横向才看得全。
**A7 降价榜 TOP 20**（表格/Table，14×8）
```sql
SELECT product_name AS 商品, shop_name AS 店铺, sku_name AS SKU,
       crawl_date AS 日期, price AS 现价, prev_price AS 昨日价,
       price_diff AS 涨跌额, change_pct AS `涨跌幅%`
FROM v_price_change
WHERE price_diff < 0
ORDER BY change_pct ASC
LIMIT 20
```
**A8 历史新低预警**（表格，10×8）——与 ⑤钉钉告警同口径
```sql
SELECT product_name AS 商品, shop_name AS 店铺, sku_name AS SKU,
       crawl_date AS 日期, price AS 现价,
       min_price_before AS 此前历史最低,
       ROUND(price - min_price_before, 2) AS 再低多少
FROM v_price_change
WHERE min_price_before IS NOT NULL AND price < min_price_before
ORDER BY price - min_price_before ASC
LIMIT 20
```
**A9 价格区间分布**（条形/Bar，10×8）
```sql
SELECT 价格带, COUNT(*) AS SKU数 FROM (
    SELECT CASE
        WHEN sku_price < 1000 THEN '01. <1000'
        WHEN sku_price < 2000 THEN '02. 1000-2000'
        WHEN sku_price < 3000 THEN '03. 2000-3000'
        WHEN sku_price < 4000 THEN '04. 3000-4000'
        ELSE '05. >=4000' END AS 价格带
    FROM v_sku_latest WHERE sku_price IS NOT NULL
) t
GROUP BY 价格带
ORDER BY 价格带
```
> 分桶写死不用自动binning：跨月可比；前缀`01.`保证语义排序。
**A10 折扣力度 TOP 20**（表格，14×8）
```sql
SELECT product_name AS 商品, shop_name AS 店铺, sku_name AS SKU,
       original_price AS 划线价, sku_price AS 现价,
       discount_rate AS `折扣(折)`, crawl_time AS 采集时间
FROM v_sku_latest
WHERE discount_rate IS NOT NULL AND discount_rate > 0
ORDER BY discount_rate ASC
LIMIT 20
```
> `discount_rate` 是"折"（8.5=八五折）非百分比；视图内算法 `sku_price/NULLIF(original_price,0)*10` 防除零。

SQL写法两特性：含 `%`/空格/括号的中文别名必须反引号；加筛选器用模板 `[[AND shop_name = {{shop}}]]`（本模块暂未用）。

## 附录B：pymysql 执行视图DDL（本机无 mysql.exe 时）
```python
import json, pymysql
cfg = json.load(open('project/config/database.json', encoding='utf-8'))
conn = pymysql.connect(**{**cfg, 'charset': 'utf8mb4'})
cur = conn.cursor()
sql = open('project/config/init_bi_views.sql', encoding='utf-8').read()
sql = '\n'.join(l for l in sql.splitlines() if not l.strip().startswith('--'))
for s in [x.strip() for x in sql.split(';') if x.strip()]:
    cur.execute(s)
conn.commit()
```
