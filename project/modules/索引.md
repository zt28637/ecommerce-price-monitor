## 复现
```
打开影刀编辑器→停在应用页
python project/tools/extract_sb_catalog.py    # 仅编辑器升级、指令中文目录需刷新时跑
python project/tools/transcribe_canvas.py     # 覆盖 project/modules 全部画布
python project/tools/transcribe_canvas.py main  # 只重转某 flow_id
```
或直接走 MCP（`.mcp.json` 已注册 `shadowbot-canvas`，Claude Code/Cursor 重启后即可调用，零依赖 stdio）：
- `sb_list_flows` — 列全部流程+画布映射状态
- `sb_get_canvas(flow_id)` — 预览单流程画布文本（只读）
- `sb_transcribe_canvas(flow_id?, dry_run?)` — 转录落盘/只比对
- `sb_refresh_catalog` — 重建中文指令目录
> flow_id→画布路径映射在 `transcribe_canvas.py` 的 FLOW_MAP；新流程先登记再重跑。
> 指令名/参数名中文来自 `tools/sb_blocks_zh.json`（426 内置 + 914 市场/自定义模块，从编辑器 DLL 与明文解包目录离线提取）。
> transcribe_flows.py（v1，产出 docs/真源转录 + wiki 英文缓存）保留作后备，画布以 transcribe_canvas.py 为准。
